# Rasa NLU DIET Classifier 核心功能分析

## 概述

`diet_classifier.py` 文件是 Rasa NLU 模块中 DIET (Dual Intent and Entity Transformer) 分类器的实现，这是一个用于同时进行意图分类和实体提取的多任务学习模型。
DIET 基于 Transformer 架构，通过共享的转换器层处理两个任务，并使用条件随机场（CRF）进行实体标记。

## 核心类：DIETClassifier

### 类继承关系
```
DIETClassifier -> GraphComponent, IntentClassifier, EntityExtractorMixin
```

### 主要功能
- **多任务学习**：同时进行意图分类和实体提取
- **Transformer 架构**：基于共享的转换器层处理文本
- **CRF 实体标记**：使用条件随机场进行序列标记
- **特征融合**：支持稀疏和密集特征的组合
- **可配置性**：丰富的配置选项支持不同场景

## 配置参数

### 1. 架构参数
- **HIDDEN_LAYERS_SIZES**：隐藏层大小
- **TRANSFORMER_SIZE**：转换器大小
- **NUM_TRANSFORMER_LAYERS**：转换器层数
- **NUM_HEADS**：注意力头数
- **SHARE_HIDDEN_LAYERS**：共享隐藏层

### 2. 训练参数
- **BATCH_SIZES**：批次大小
- **EPOCHS**：训练轮数
- **LEARNING_RATE**：学习率
- **RANDOM_SEED**：随机种子
- **BATCH_STRATEGY**：批次策略

### 3. 嵌入参数
- **EMBEDDING_DIMENSION**：嵌入维度
- **DENSE_DIMENSION**：密集维度
- **CONCAT_DIMENSION**：连接维度
- **NUM_NEG**：负样本数

### 4. 正则化参数
- **DROP_RATE**：丢弃率
- **REGULARIZATION_CONSTANT**：正则化常数
- **CONNECTION_DENSITY**：连接密度
- **SPARSE_INPUT_DROPOUT**：稀疏输入丢弃

### 5. 评估参数
- **EVAL_NUM_EPOCHS**：评估轮数
- **EVAL_NUM_EXAMPLES**：评估样本数
- **TENSORBOARD_LOG_DIR**：TensorBoard 日志目录
