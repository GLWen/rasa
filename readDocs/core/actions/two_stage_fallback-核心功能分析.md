# Rasa Core Two Stage Fallback 核心功能分析

## 概述

`two_stage_fallback.py` 文件是 Rasa 核心模块中两阶段回退动作的实现，用于处理 NLU 预测置信度低的情况。两阶段回退机制提供了一种优雅的方式来处理用户输入不明确或超出范围的情况，通过两个阶段的交互来澄清用户意图。

## 核心类：TwoStageFallbackAction

### 类继承关系
```
TwoStageFallbackAction -> LoopAction -> Action
```

### 主要功能
- **两阶段回退机制**：实现确认和重述两个阶段的回退处理
- **意图澄清**：帮助用户澄清不明确的意图
- **智能放弃**：在多次失败后优雅地放弃回退
- **消息回退**：支持用户话语的回退和重新处理

## 核心功能模块

### 1. 两阶段回退机制

#### 1.1 主执行逻辑
```python
async def do(self, output_channel, nlg, tracker, domain, events_so_far):
    """执行两阶段回退的主要逻辑"""
```

**功能说明：**
- 根据用户状态决定执行确认还是重述
- 第一阶段：询问用户确认（affirmation）
- 第二阶段：询问用户重述（rephrase）

**执行流程：**
1. 检查用户是否应该确认
2. 如果需要确认，执行确认逻辑
3. 否则执行重述逻辑

#### 1.2 确认阶段
```python
async def _ask_affirm(self, output_channel, nlg, tracker, domain):
    """询问用户确认"""
```

**功能说明：**
- 创建并执行询问确认动作
- 询问用户是否确认之前的意图预测
- 提供用户澄清意图的机会

#### 1.3 重述阶段
```python
async def _ask_rephrase(self, output_channel, nlg, tracker, domain):
    """询问用户重述"""
```

**功能说明：**
- 创建并执行询问重述动作
- 要求用户重新表达他们的意图
- 提供用户重新输入的机会

### 2. 完成条件判断

#### 2.1 完成检查
```python
async def is_done(self, output_channel, nlg, tracker, domain, events_so_far):
    """检查两阶段回退是否完成"""
```

**完成条件：**
- **用户已澄清**：意图不是回退或超出范围
- **连续两次回退**：连续两次触发回退机制
- **第二次确认失败**：确认阶段失败

**功能说明：**
- 基于用户意图状态判断回退是否完成
- 支持多种完成条件
- 防止无限循环

### 3. 停用处理

#### 3.1 停用逻辑
```python
async def deactivate(self, output_channel, nlg, tracker, domain, events_so_far):
    """停用两阶段回退"""
```

**停用策略：**
- **放弃回退**：如果连续两次回退或第二次确认失败
- **回退事件**：否则回退用户话语并重新处理

**功能说明：**
- 根据回退状态决定停用策略
- 支持事件回退和重新处理
- 提供优雅的失败处理

#### 3.2 放弃处理
```python
async def _give_up(self, output_channel, nlg, tracker, domain):
    """放弃回退，执行默认回退动作"""
```

**功能说明：**
- 在多次失败后执行默认回退动作
- 提供最后的回退机制
- 确保对话能够继续

## 两阶段回退流程

### 1. 激活阶段
- 检测到 NLU 预测置信度低
- 激活两阶段回退循环
- 准备执行回退逻辑

### 2. 第一阶段：确认
- 询问用户是否确认之前的意图预测
- 等待用户确认或拒绝
- 如果确认，回退完成
- 如果拒绝，进入第二阶段

### 3. 第二阶段：重述
- 询问用户重新表达意图
- 等待用户重新输入
- 如果成功，回退完成
- 如果失败，检查放弃条件

### 4. 完成检查
- 检查用户是否已澄清意图
- 检查是否连续两次回退
- 检查是否第二次确认失败
- 根据检查结果决定下一步

### 5. 停用处理
- 如果成功澄清，回退事件并重新处理
- 如果多次失败，执行默认回退动作
- 清理回退状态

## 设计特点

### 1. 渐进式回退
- 从确认到重述的渐进式处理
- 避免直接放弃用户输入
- 提供多次澄清机会

### 2. 智能放弃
- 基于历史模式检测失败
- 防止无限循环
- 提供优雅的失败处理

### 3. 事件驱动
- 基于事件历史进行决策
- 支持事件回退和重新处理
- 保持状态一致性

### 4. 可配置性
- 支持自定义动作端点
- 可扩展的回退策略
- 灵活的完成条件

### 5. 错误处理
- 完善的异常处理机制
- 优雅的失败恢复
- 用户友好的错误信息

## 使用场景

### 1. NLU 置信度低
- 意图预测置信度低于阈值
- 用户输入不明确
- 需要用户确认

### 2. 意图超出范围
- 用户意图不在训练范围内
- 需要引导用户重新表达
- 提供澄清机会

### 3. 多轮澄清
- 复杂的用户输入
- 需要多次交互澄清
- 渐进式意图确认

### 4. 错误恢复
- 处理用户输入错误
- 提供重新输入机会
- 保持对话流畅性

`two_stage_fallback.py` 文件是 Rasa 回退处理系统的核心实现：

- **智能的两阶段回退**：从确认到重述的渐进式处理
